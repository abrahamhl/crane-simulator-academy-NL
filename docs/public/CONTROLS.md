# Controls

**The same gesture means the same thing on every machine.** That is the whole
design rule. A learner who has driven the workshop crane already knows two
thirds of the mobile crane's controls.

Everything below is also available in-game: the **Controls** entry in the main
menu, **F1** at any moment, and the pause screen (**ESC**).

## Operating any machine

| Keys | What it does | On which machine |
|---|---|---|
| **W / S** | Reach **out / in** | Bridge forward/back (overhead, gantry) · Trolley out/in along the jib (tower) · Telescope out/in (mobile, lorry loader) |
| **A / D** | **Left / right** | Trolley across the bridge (overhead, gantry) · **Slew** left/right (tower, mobile, loader, railway) |
| **R / F** | Hoist **raise / lower** | **Identical on every machine.** R = raise, F = fall |
| **T / G** | Boom **up / down** (luff) | Mobile crane, lorry loader, railway crane |
| **Q / E** | Travel along the track | Railway crane only |
| **SHIFT** | Creep / fine mode — hold for precision | All |
| **SPACE** | **ALL STOP** — brakes every axis | All |
| **O** | Deploy / stow outriggers | Machines that have them |
| **1 2 3 4** | Pre-use checks — the machine will not power up until they pass | All |
| **H** | Load chart and lift plan | All |
| **B** | Call the signaller | All |
| **X** | Put the controls down / leave the machine | All |
| **BACKSPACE** | Reset the machine (never your own position) | All |

## Gamepad

Left stick drives the machine in plan (reach and left/right), right stick
handles the boom and the rope, left shoulder is creep, **B** is ALL STOP.
Analogue sticks are proportional, which is closer to a real control lever than
the keyboard's on/off is.

## The first thing to do

1. Walk to the **marked control position** (orange disc on the ground) and
   press **E**.
2. If the machine has outriggers, hold **O** until they are fully down. Nothing
   slews, luffs or telescopes before then — that interlock is real.
3. Run the pre-use checks with **1 2 3 (4)**. The machine is dead until you do.
4. Press **H** and read the load chart before you lift anything.
5. **R / F** to lower the hook onto the load, then travel.

The blue strip at the top of the screen always tells you the next step, and the
keys light up on the bar at the bottom as you press them.
