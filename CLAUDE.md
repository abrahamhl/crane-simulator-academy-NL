# Gelderland Operator Academy

@AGENTS.md

## Project mission
Build an evidence-driven desktop training simulator and career-preparation system for crane, lifting, excavator, terminal and selected rail-heavy-equipment roles near Arnhem.

## Persistent rules
- Read `01_MASTER_PROMPT_V2.md` for full scope.
- Desktop-first. Default to Godot 4.6 stable + Jolt; web export is secondary.
- Never invent vacancies, licences, salaries, language acceptance, experience or certification.
- “English confirmed” requires explicit current evidence.
- “Paid from day one” and “employer-funded training” require explicit evidence.
- Simulator performance never equals legal certification.
- Safety outranks speed and visual spectacle.
- Three deep vertical slices beat ten shallow demos.
- Keep raw research in `research/raw/`; keep summaries concise.
- Use stable IDs for vacancies, licences, scenarios, decisions and tests.
- Record decisions, not private chain-of-thought.
- Prefer scripts, tests, hooks and engine diagnostics over repeated model inspection.
- No MCP server is required by default.
- Update `PROJECT_STATE.md` and `SESSION_HANDOFF.md` before ending a milestone.
